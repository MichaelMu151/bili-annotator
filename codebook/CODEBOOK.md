# 标注手册 / Codebook (v1.0-draft)

> **状态**: draft v1.0。示例为"暂定锚例"，**决策卡（decision cards）待 pilot 产出正/负例后固化**（见 §7）。
> **原则**: 标注单元是"**一条评论 + 它的上下文卡**"；一切标签必须能指向**原文证据片段**，否则标 `ambiguous`。
> 本手册的中/英定义系**综合转述（paraphrase）**，来源仅作可追溯指引，非逐字引用。

---

## 0. 标注单元与上下文卡

每条待标评论呈现为一张卡：

| 区块 | 内容 | 用途 |
|---|---|---|
| `[VIDEO]` | 视频标题 / UP / 标签 / 摘要（**可编辑**）+ BV 链接 | 宏观氛围先验；建议亲自看视频核对 |
| `[ANCHOR]` | 本分支 root（楼层根的直接子回复，或根本身）原文 + **人工 anchor claim（≤30字）** | 维度 3 的漂移基准 |
| `[PATH]` | 祖先链 `root → … → parent` 逐字 | 微观结构上下文（在回谁、被谁引导） |
| `[CORE]` | `C_core`：同楼层 `t ≤ parent` 的评论（最近 ≤5 条 + 楼层根） | 必读下界（meso 上下文） |
| `[TARGET]` | 待标评论原文 | 标注对象 |

> 标注时**不看**后续评论（避免 hindsight bias）；`C_extra`（溢读带）仅供模型/分析使用，不呈现给人工。

## 1. 维度 1 · 修辞策略与讽刺细分

**构念定义（D1）**：评论所采用的**修辞/语用形式**（"怎么说"），与说话者意图（D2）正交。
**量表**：**多标签 0/1**（可同时命中多个）+ 一个 **主标签 primary** + `is_mixed` 标记；不可判定 → `ambiguous`。

| 子类 | 可观察判据（operational） | 典型形态 |
|---|---|---|
| **1.1 反讽/倒置** | 字面表述与说话者真意**方向相反**，且能指出"预期差"的存在 | "劳动法执行得可真严格啊" |
| **1.2 嘲讽/挖苦** | 针对**特定主体**（人/平台/制度）的尖锐贬抑，常含人身/能力反讽 | "资本家看了都流泪，真是大善人" |
| **1.3 犬儒虚无/反向解构** | 宣告**讨论/行动本身无意义**的"话语终止器"，**不提供替代方案** | "急了""赢麻了""典中典""开香槟" |
| **1.4 自嘲/苦情** | 把**自身**客体化、以自嘲表达处境/结构性无力 | "牛马不配休假""工贼竟是我自己" |
| **1.5 直白陈述** | **无修辞反转**，字面即真实意图 | 直接陈述事实/立场/信息 |

**不成立的边界**（负例，暂定）：
- 1.3 ≠ 单纯骂人（那是 2.4）；1.3 要求指向"讨论无意义"。
- 1.4 ≠ 单纯示弱求助（无"自我客体化/自嘲"则不算）。
- 1.1 与 1.2 可叠加：主=1.2、次=1.1 也合法。

**来源指引**：Grice (1975) 会话含义；Sperber & Wilson (1986) *Relevance*（反讽的"回声/提及"观）；《现代汉语词典》"反讽/嘲讽"义项；Oxford English Dictionary "irony / sarcasm"。

## 2. 维度 2 · 语用动机与言语行为

**构念定义（D2）**：评论**试图达成什么**（"为什么说"），即言语行为/交际意图。
**量表**：**多标签 0/1** + **主标签** + `is_mixed`。

| 子类 | 可观察判据 | 典型形态 |
|---|---|---|
| **2.1 建设性论辩** | 提出**主张** + 给出**事实/法律/制度**理据 | 论证、举证、制度分析 |
| **2.2 情绪共鸣/连带** | 表达**同理心**、控诉**共同遭遇**、寻求身份认同 | "我们也一样""太真实了" |
| **2.3 动机怀疑/诛心** | **不讨论事实**，转而攻击对方**立场/"屁股"/成分** | "洗地的收了多少钱""你成分复杂" |
| **2.4 纯泄愤/对抗** | **人身攻击**、污名化、脏话、扣帽子 | 辱骂、侮辱 |
| **2.5 虚无解构/劝退** | **主动劝阻**抗争/行动："别白费力气" | "别折腾了，没用的""嫌累辞职啊" |

**不成立的边界**（负例，暂定）：
- 2.5 ≠ 1.3：2.5 针对**具体行动**劝阻；1.3 针对**讨论本身**宣告无意义。
- 2.3 ≠ 2.4：2.3 至少**伪装成"分析动机"**；2.4 是**赤裸人身攻击**。
- 2.1 与 2.2 可共存（既讲理又共情）→ `is_mixed`。

**来源指引**：Austin (1962) *How to Do Things with Words*；Searle (1969, 1975) 言语行为；Walton (1998) *Ad Hominem Arguments*（2.3/2.4 的区分）。

## 3. 维度 3 · 议题漂移与偏离机制

**构念定义（D3）**：评论与**锚点（anchor claim）**的**话题关系**。两个独立字段：`type`（关系类型）与 `extent`（偏离程度）。

**3.1 type（单选）**

| 子类 | 判据 |
|---|---|
| **3.1 议题聚焦** | 紧扣锚点核心命题 |
| **3.2 合理议题延展** | 由锚点引申到宏观/**相关**议题（立法、行业、制度） |
| **3.3 离题转移/围魏救赵** | 引入**不相关**外部矛盾转移视线（"别国更黑""外卖员素质低"） |
| **3.4 元争论/辨经** | 不讨论议题，转而纠缠**用词/资格/立场站队**（滑向男女对立、地域、意识形态） |

**3.2 extent（序数 1–4）**：1=紧贴锚点；2=合理延展；3=明显偏移；4=完全离题。
> extent 与自动 embedding 距离互为验证；**人工给序数，模型给连续距离**，不一致者进复核。

**锚点规则**：锚点 = **分支 root 的命题**（人工写 `anchor claim ≤30 字`）。
- 若分支 root 本身已离题 → 锚点退化为**楼层 root 命题**，并在备注标 `anchor_degraded`。
- 无主命题（纯情绪/纯表情）→ `anchor claim` 记为"（无明确命题）"。

**来源指引**：Grice (1975) 关系准则；Sperber & Wilson (1986) 关联理论；Dziri et al. (2021) 对话 derailment 研究。

## 4. 维度 4 · 基础情感与攻击强度

**构念定义（D4）**：评论的**情感极性/唤醒度**与**毒性等级**（三者**解耦**，不可互相替代）。

| 字段 | 量表 | 判据 |
|---|---|---|
| **极性 polarity** | `-1 / 0 / +1` | 负向 / 中性 / 正向（对**评论内容**的整体评价倾向） |
| **唤醒度 arousal** | `low / high` | 低唤醒（麻木/沮丧/平静） vs 高唤醒（愤怒/激动/亢奋） |
| **毒性 toxicity** | `0–3` 序数 | 0=无攻击；1=隐性攻击（阴阳怪气/微侵犯）；2=显性恶毒（辱骂）；3=骚扰/威胁/人肉 |

**关键区分**：毒性 ≠ 负向情感。`牛马` 可自嘲（负向但低毒）；`哥谭小丑` 可戏谑也可攻击——**必须看上下文**。

**来源指引**：Sue et al. (2007) 微侵犯（microaggression）；Dixon et al. (2012) / Davidson et al. (2017) 毒性/仇恨言论标注；Perspective API 毒性分级实践。

| 字段 | 说明 |
|---|---|
| `ambiguous` | **无法判定/证据不足**时勾选；这是合法结果，不是失败 |
| `confidence` | `high / medium / low`：你对本次判断的把握 |
| `notes` | 疑问、边界案例、建议补充分层 |

## 6. 一致性规则（重要）

1. **主标签必须 ∈ 已选标签**（前端会校验）。
2. **多标签合法**：D1/D2 各自可多选；`is_mixed` 表示"确实混合、难分主次"。
3. **D3 type 单选**；`extent` 独立。
4. **D1 与 D2 正交**：允许"反讽 + 建设性"这类组合。
5. **证据优先**：D3/D4 建议填 `evidence`（原文片段），否则易被复核打回。
6. **不勉强**：无法判定 → `ambiguous`，并在 `notes` 说明。

## 7. 决策卡（Decision Cards）

> **状态：模板已就绪，等待 pilot 的真实正/负例回填。**
> 决策卡的价值来自"**近似但不算**"的负例，只能从 pilot 双标分歧里长出来。
> 流程：≥2 名标注员标同一小批（50–80 条）→ 在 **「分歧裁决」页** 逐维度裁决 →
> 把典型分歧的正/负例回填到下面的卡片。**每条裁决都应指向具体 `unit_id` 作为可追溯样例。**

### 7.1 卡片模板（每对易混类一张，复制使用）

```
#### 卡片 X：<类A> vs <类B>
- 判据（decision rule，一句话）：
- 关键鉴别问句（用"是/否"逐步收敛）：
  1) ...? 是→A / 否→B
  2) ...?
- 正例 A（unit_id=..., 原文："..."）：为什么是 A
- 负例（原以为 A 但其实是 B，unit_id=..., 原文："..."）：为什么是 B
- 灰色地带处理（两者皆沾时）：主=A、次=B，或标 is_mixed / ambiguous
```

### 7.2 预置待填充卡片（pilot 重点观察对象）

> 以下 6 对是维度内/维度间最容易翻车的组合，先从它们的真实分歧里提炼判据。

#### 卡片 1：1.3 犬儒 vs 2.4 纯泄愤
- 判据：针对**"讨论/行动本身无意义"** → 1.3；针对**"人"的侮辱** → 2.4。
- 鉴别问句：① 是否在羞辱具体的人？是→2.4 否→②；② 是否宣告"说了也没用/散了吧"？是→1.3。
- 灰色：`急了` 后可接人身攻击 → 主 2.4、次 1.3（在「分歧裁决」记录）。

#### 卡片 2：1.3 犬儒 vs 2.5 劝退
- 判据：2.5 针对**具体行动**劝阻（"别去举报了"）；1.3 针对**讨论本身**宣告无意义（"这有啥好吵的"）。
- 灰色：难以区分时看**是否有替代建议/指向行动**。

#### 卡片 3：2.3 诛心 vs 2.4 对抗
- 判据：2.3 至少**伪装成"分析动机"**（"收了多少钱""成分复杂"）；2.4 是**赤裸辱骂/扣帽**。
- 灰色：`你就是个洗地的` —— 有人身指向但无脏词 → 倾向 2.3。

#### 卡片 4：1.1 反讽 vs 1.2 嘲讽
- 判据：1.1 靠**字面与真意相反**（预期差）；1.2 是**直接尖锐贬抑**（可含人身反讽）。
- 灰色：二者常叠加 → 主选更主导的一种，另一个进次标签。

#### 卡片 5：1.4 自嘲 vs 2.2 情绪共鸣
- 判据：1.4 是**自我客体化**（"牛马竟是我自己"）；2.2 是**向外寻求认同/连带**（"我们也一样"）。
- 灰色：`你也是牛马` 指向他人 → 2.2；指向自己 → 1.4。

#### 卡片 6：D3 离题转移(3.3) vs 元争论(3.4)
- 判据：3.3 引入**不相关外部矛盾**（"别国更黑"）；3.4 纠缠**用词/资格/站队**（滑向男女、地域）。
- 锚点规则：二者都需参照 **anchor claim**；无明确锚点时优先判 3.1/3.2 并标 `anchor_degraded`。

### 7.3 暂定裁决示例（占位，pilot 后替换为真实 `unit_id` 与原文）

- `急了` 单独出现 → 1.3；紧跟具体人身侮辱 → 主 2.4、次 1.3。
- `你收了多少钱` → 2.3（伪装分析动机），不判 2.4（无人身辱骂词）。
- `别折腾了` → 2.5（劝阻行动）；`这讨论没意义` → 1.3（宣告讨论无意义）。

## 8. 标注流程与数据说明

- **标注员**：右上角填写名字（本地保存，用于多人区分与一致性统计）。
- **进度**：顶栏 chip 显示"你已完成 / 总数"；「进度 / 质检」页有总体覆盖、维度填写率、单元列表。
- **草稿**：切换单元/刷新自动本地暂存，防丢。
- **分歧裁决**：「分歧裁决」页集中展示多人判断不一致的单元，逐维度选定最终值并写判据，存入 `adjudications` 表（不改动原始标注），用于回填 Codebook §7 决策卡。
- **导出**：`/api/export` 输出分析用 CSV（含 `inclusion_prob` 等抽样权重）。
- **溯源**：每条单元保存 `stratum`、`stratum_n`、`inclusion_prob`、`sampled_by`；采样 seed 存于 `meta.sampling.seed`。
- **一致性（IAA）**：多人重叠标注后运行 `python scripts/compute_iaa.py`。
